# 이음선 소개 사이트

코틀린 Android 앱 이음선의 정적 소개 페이지입니다. Google·통신사 연결 상태를 읽지 않는 설명용 예제가 포함되며 데이터 전송, 추적 스크립트, 외부 글꼴이 없습니다.

## 개발과 빌드

```sh
npm ci
npm run dev -- --host 127.0.0.1
npm run build
npm run preview -- --host 127.0.0.1
```

개발 서버 기본 주소는 http://127.0.0.1:5173, 빌드 미리보기 기본 주소는 http://127.0.0.1:4173입니다. 서버 종료는 해당 터미널에서 Ctrl+C. Node.js 22 이상 권장.

## Cloudflare Pages

| 항목 | 값 |
|---|---|
| GitHub 저장소 | `hslcrb/ieumseon` |
| 운영 브랜치 | `main` |
| 루트 디렉터리 | `site` |
| 빌드 명령 | `npm run build` |
| 빌드 출력 | `dist` |
| 빌드 환경 | Node.js 22 |

Pages의 Git 연결을 사용하며 이 페이지에는 별도 서버, 비밀값 또는 GitHub Actions가 필요 없습니다.

## 조작 범위

상황 체험은 일반 HTML 라디오 버튼을 사용합니다. 키보드 화살표로 고를 수 있으며, 예시 상태를 접근성 도구에도 알립니다. 세 상황의 문구는 모두 가상값이며 현재 사용 기기의 상태를 뜻하지 않습니다. 자바스크립트가 없으면 기본 예시는 읽을 수 있지만 선택은 비활성화됩니다.
