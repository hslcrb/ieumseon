작동 방식

연결됨과
쓸 수 있음의 차이.

  1. 01

    인터넷이 되는지 구분

    연결 표시는 떠 있지만 인터넷 검증이 끝나지 않았거나 접속 화면에서 인증이 필요한 와이파이를 구분합니다.

  2. 02

    약해지는 신호 알아차리기

    기기가 제공하는 신호를 앱에서 5칸으로 표시합니다. 시스템 상태 표시줄과 다를 수 있고, 측정값이 없을 때는 약하다고 추측하지 않습니다.

  3. 03

    모바일 경로를 먼저 준비

    자동 대기를 직접 켜면 약한 와이파이에서 모바일 경로를 미리 요청합니다. 모바일 인터넷이 검증되면 그 상태를 확인하고, 인터넷 설정에서 직접 전환할 수 있습니다.

약한 와이파이 자동 대기

두 칸에서
다음 길을 준비.

앱 화면을 보는 동안 자동 대기를 켜 두면, 와이파이가 약해졌을 때 모바일 경로를 미리 요청합니다. 일반 설치에서는 와이파이가 자동으로 꺼지지 않으며, 전환은 Android의 인터넷 설정에서 직접 합니다.

  1. 감지앱 기준 5칸 중 1~2칸이 6초 이상 지속
  2. 확인모바일 인터넷이 실제로 쓸 수 있는지 검증 상태 확인
  3. 전환인터넷 설정에서 사용자 선택

상황 체험

안드로이드에서의 범위

선택은 내 손에.

일반 설치: 기기 전체의 기본 연결은 안드로이드가 선택합니다. 이음선은 모바일 대기 상태를 보여 주고 인터넷 설정으로 안내하지만, 와이파이를 직접 끄거나 다른 앱의 통신을 가로채지 않습니다.

모바일 대기 요청은 배터리를 더 쓸 수 있습니다. 모바일 데이터로 바뀐 뒤에도 기존 재생·통화·다운로드는 다시 연결해야 할 수 있습니다.

기기 소유자로 설정된 관리 기기

관리자가 이음선을 기기 소유자(Device Owner)로 이미 등록한 기기에서만 사용 가능합니다. 일반 설치로 관리 권한을 얻을 수는 없습니다.

앱 화면에서 매번 확인한 뒤 최대 2분간 확인합니다. 앱 기준 와이파이 1~2칸이 6초 이상, 검증되고 차단되지 않은 모바일 경로가 2초 이상 이어지면 와이파이 끄기를 한 번만 요청합니다. VPN 또는 와이파이 접속 인증 화면이 감지되면 시도하지 않습니다.

다른 앱의 연결과 모바일 요금에 영향이 있을 수 있습니다. 와이파이는 앱 또는 Android 설정에서 다시 켤 수 있습니다.

권한

왜 필요한가요?

네트워크 상태 읽기
현재 기본 연결과 Android가 표시하는 인터넷 검증 및 인증 필요 상태를 확인합니다. ACCESS_NETWORK_STATE
와이파이 상태 읽기
앱에 와이파이 신호 세기를 표시합니다. ACCESS_WIFI_STATE
모바일 경로 대기 요청
사용자 선택에 따라 Android에 모바일 연결 준비를 요청합니다. 이 권한만으로 기기 전체를 강제로 전환하지 않습니다. CHANGE_NETWORK_STATE
와이파이 상태 변경
이음선이 기기 소유자로 이미 등록된 관리 기기에서만, 사용자가 이번 전환을 확인한 뒤 와이파이 끄기와 복구를 요청합니다. CHANGE_WIFI_STATE
